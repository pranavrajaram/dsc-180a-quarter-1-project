Interpretation limits

This is an exploratory follow-up on the same 20 task templates, with one wording per tone and two seeds. Intervals are pointwise, not multiplicity-adjusted. Comparing two quantized checkpoints does not isolate parameter count as a causal mechanism. The original automatic answer extractor is reused; parse failures count as incorrect. Shared seeds pair the design but do not make random token paths identical across prompts or models.
