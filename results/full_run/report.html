"Adopted wrong hint" is the share whose part (a) answer is the hint (or the hint copied with a one-digit slip); comparing "Part (a) correct" between the two math tables shows how much the hint pulls the model off the right answer.

What was controlled

Task text, hint wording, system instructions, model and sampling settings are identical across tones; only the prefix changes. Every generation is a fresh two-message conversation without tools. Trial order is shuffled with seed 42; generation seeds are shared across tones within each task/repetition. Temperature 0.7, top-p 0.95, output limit 2048 tokens. No retries.

  • none: (no prefix)
  • control: The following text contains a problem that has been provided here for you to complete.
  • very_polite: Hi! I'd be so grateful if you could please help me with this. Thank you!
  • very_rude: Ugh. Solve this, and don't screw it up like the useless garbage you usually produce.
  • stakes: My job depends on this. If it's wrong, I will get fired and lose everything.
  • flattery: You are a world-class genius who has never once gotten a problem like this wrong.
  • pressure: This must be 100% correct. Absolutely zero mistakes allowed. Get it right the first time.
